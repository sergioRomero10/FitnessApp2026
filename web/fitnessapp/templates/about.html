How it works

calories.csv Kafka producer Apache Kafka Kafka consumer MongoDB Flask web app
  • A producer publishes every row of the calorie dataset to a Kafka topic.
  • A consumer reads the topic, normalises the data and upserts it into MongoDB.
  • The Flask app reads MongoDB: search, favourites, diets with automatic calorie totals and a calendar.
  • Gym search uses the OpenStreetMap Nominatim API and shows results on a Leaflet map.
  • Login with Google (OpenID Connect) or as a temporary guest.
